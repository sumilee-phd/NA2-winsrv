# 윈도우 서버 설정 연습

공개 주소: https://sumilee-phd.github.io/NA2-winsrv/ · 저장소: https://github.com/sumilee-phd/NA2-winsrv (2026-11-16 공개)

네트워크관리사 2급 실기의 윈도우 서버 설정 문항을 연습하는 웹 시뮬레이터입니다. 네트워크 속성(TCP/IPv4), 로컬 보안 정책(암호·계정 잠금), DHCP(새 범위 마법사), DNS(새 영역·호스트·별칭·SOA) 4유형을 큰 글자 화면에서 연습하고, 최종 설정값을 조건과 대조해 채점합니다. 빌드 과정이 없는 정적 파일(HTML·CSS·JS)이며 설치와 로그인이 없습니다.

작성: 2026-11-15. 상태: MVP. 로컬 실행 확인 뒤 2026-11-16 GitHub Pages로 공개했습니다.

## 만든 원칙

- **가독성 우선**: 협회 연습 프로그램의 작은 창 대신 작업 화면 글자를 18px(세로 900px 이상 화면은 20px)로 시작하고, 위 막대의 「가−」 「가+」로 16~26px 사이에서 바꿉니다. 모든 창·대화상자·메뉴가 이 크기를 따라 커집니다. 12px 이하 글자는 쓰지 않습니다.
- **Windows 창 색과 느낌**: 파랑 제목 표시줄, 은색(밝은 회색) 대화상자, 흰 탭 페이지, 회색 단추, 하늘색 선택 표시, 파랑 바탕 화면과 검은 작업 표시줄로 실제 서버 관리 창과 같은 느낌을 줍니다(2026-11-15 사용자 지시). 창 안 글꼴은 맑은 고딕입니다.
- **칸 이름과 동작**: 실기 시험 연습 프로그램의 한국어 표기를 따랐습니다. Windows Server 2022(영어판) 화면 캡처로 기본값과 동작을 함께 대조했습니다.
- **새로 만든 것**: 과제의 주소·이름·수치는 모두 연습용으로 새로 정했습니다. Microsoft 아이콘·로고 그림은 쓰지 않았고 아이콘은 단순 도형으로 직접 그렸습니다. 설명 문장도 새로 썼습니다.
- 시험 과제에 쓰지 않는 메뉴와 탭은 비활성으로 두고 「연습 범위 밖」 표시를 붙였습니다.

## 과제(4유형 16개)

| 유형 | 과제 |
|---|---|
| 1 네트워크 속성 | 1-1 고정 IP와 DNS 지정 · 1-2 접두 길이(/25)를 마스크로 바꿔 입력, 마지막 사용 가능 주소를 게이트웨이로 · 1-3 두 연결 가운데 「로컬 영역 연결 2」에만 지정 · 1-4 고정 설정을 자동 받기로 되돌리기 |
| 2 로컬 보안 정책 | 2-1 최소 길이·기억 개수·복잡성 · 2-2 최대·최소 사용 기간과 해독 가능한 암호화 끄기 · 2-3 잠금 임계값 → 제안 값 → 잠금 기간 15분 · 2-4 잠금 기간 0(관리자 해제)과 원래대로 설정 20분 |
| 3 DHCP | 3-1 새 범위·제외 범위·임대 4시간·옵션 나중에(비활성) · 3-2 /26 범위와 라우터·DNS·도메인 옵션, 바로 활성화 · 3-3 /20 범위와 제외 주소 두 개(단일 주소 포함) · 3-4 만든 범위의 임대 기간 고치기·제외 범위 추가·활성화 |
| 4 DNS | 4-1 새 주 영역과 호스트(A) · 4-2 호스트 하나에 별칭(CNAME) 두 개 · 4-3 SOA 일련 번호·주 서버·책임자·시간 값(초로 제시, 단위 환산) · 4-4 영역 생성부터 이름 서버 호스트·SOA 「증가」까지 |

과제 화면 왼쪽에는 문제, 조건 표, 작업 순서(닫을 수 있음), 채점 기준이 있고, 오른쪽에는 서버 바탕 화면과 관리 도구 4개가 있습니다. 어느 과제에서나 도구 4개가 모두 열리므로 알맞은 도구를 직접 골라야 합니다.

## 화면에서 재현한 동작

| 도구 | 동작 | 기준 |
|---|---|---|

| IP 주소 칸 | 네 칸 입력. 숫자 세 자리나 점(.)으로 다음 칸, 빈 칸에서 Backspace로 앞 칸, 255를 넘으면 경고 후 255. Tab은 네 칸을 건너 다음 항목으로. 붙여넣기는 네 칸에 나눠 넣음 | Windows IP 주소 컨트롤 |
| 로컬 보안 정책 | 보안 설정 > 계정 정책 > 암호 정책·계정 잠금 정책. 기본값(복잡성 사용 안 함, 0개, 42일, 0문자, 0일, 해당 없음). 임계값을 정하면 「제안된 값 변경」 창이 잠금 기간·원래대로 설정 30분을 제안. 잠금 기간을 원래대로 설정 시간보다 짧게 바꾸면 맞춰 줄이자고 제안. 임계값 0이면 두 항목은 「해당 없음」으로 바꿀 수 없음 | WS2022 캡처 02a~02g, 연습 프로그램 화면 |
| DHCP | 트리에서 IPv4를 먼저 왼쪽 단추로 선택해야 「새 범위」가 활성. 마법사 11단계, 길이 기본 24, 길이와 마스크 연동. 제외 범위는 「추가」로 목록에 올린 것만 반영. 임대 기본 8일. 옵션을 나중에 구성하면 비활성 범위. 범위 표시는 「범위 [시작 주소] 이름」. 범위 속성·새 제외 범위·옵션 구성·활성화/비활성화·삭제 | WS2022 캡처 03a~03n, 연습 프로그램 기록 |
| DNS | 트리에서 「정방향 조회 영역」을 먼저 선택해야 「새 영역」이 활성. 새 영역 마법사(주·보조·스텁, 영역 파일 이름 자동, 동적 업데이트 기본 「허용 안 함」). 영역의 오른쪽 단추 메뉴로 새 호스트·새 별칭·속성. 새 호스트 창은 추가 뒤에도 열려 있음. 같은 이름의 CNAME과 다른 레코드는 함께 둘 수 없음. SOA 기본값(일련 번호 1, 15분, 10분, 1일, 1시간, 0:1:0:0)과 단위 목록(초·분·시간·일), 「증가」 단추 | WS2022 캡처 04a~04o, 연습 프로그램 기록 |

## 채점

「채점」을 누르면 항목마다 조건 값과 현재 설정값을 나란히 보여 줍니다. 최종 설정값만 보고 조작 순서는 보지 않습니다.

- IP 주소는 앞자리 0을 뺀 같은 주소로 비교합니다.
- DNS 이름은 대소문자와 끝의 점(.)을 구분하지 않습니다.
- SOA 시간 값은 초로 바꿔 비교합니다. 7200초를 「2 시간」 「120 분」 「7200 초」 어느 단위로 넣어도 같습니다.
- 범위 이름은 앞뒤 공백만 무시하고 글자를 그대로 비교합니다.

채점은 이 연습기의 기준입니다. 실제 시험의 채점 기준은 공개되지 않았습니다. 시험 전 마지막 연습은 협회 자료실의 공식 연습 프로그램으로 합니다.

## 실행 방법

`index.html`을 더블클릭하면 열립니다. 외부 요청은 글꼴(Pretendard, jsDelivr) 하나뿐입니다. GitHub Pages와 같은 조건으로 보려면 이 폴더에서 로컬 서버를 띄웁니다.

```powershell
python -m http.server 8775 --bind 127.0.0.1
```

`http://127.0.0.1:8775/`를 엽니다. ICT폴리텍 저장소의 `.claude/launch.json`에 같은 설정(`na2-winsrv`)이 있습니다. 주소 뒤에 `?task=dhcp-2`처럼 과제 id를 붙이면 그 과제로 바로 들어갑니다. 권장 화면은 PC 브라우저, 가로 1000px 이상입니다.

진행 상태와 채점 기록은 브라우저 저장소(`localStorage`, 키 `na2-winsrv-v1`)에만 남고 서버로 보내지 않습니다. 첫 화면 맨 아래 「연습 기록 모두 지우기」로 지웁니다.

## 단순화한 부분

- 화면 크기는 시험 프로그램보다 크고, 창은 작업 영역 안에 꽉 차게 열립니다(창 크기 조절·겹쳐 놓기 없음). 대화상자는 제목 표시줄을 끌어 옮길 수 있습니다.
- 연결 아이콘을 두 번 누르면 상태 창이 열리고, 상태 창의 「자세히」에서 현재 IPv4 값을 볼 수 있습니다. 「대체 구성」 「고급」은 다루지 않습니다.
- DHCP 범위 옵션은 003 라우터, 006 DNS 서버, 015 DNS 도메인 이름만 다룹니다. 서버 옵션·예약·정책·필터·IPv6는 다루지 않습니다.
- DNS는 정방향 조회 영역만 다룹니다. 「연결된 PTR 레코드 만들기」를 고르면 역방향 영역이 없다는 안내만 나옵니다. 보조·스텁 영역은 만들 수 있지만 채점 과제는 주 영역입니다.
- 계정 잠금 기간·원래대로 설정 시간은 임계값이 0일 때 바꿀 수 없게 했습니다(Windows에서 「해당 없음」으로 표시되는 상태).
- 명령 프롬프트(ipconfig, nslookup)는 없습니다.
