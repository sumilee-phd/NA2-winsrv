# 윈도우 서버 설정 연습

공개 주소: https://sumilee-phd.github.io/NA2-winsrv/ · 저장소: https://github.com/sumilee-phd/NA2-winsrv (2026-11-16 공개)

네트워크관리사 2급 실기의 윈도우 서버 설정 문항(2~9번, 8유형)을 연습하는 웹 시뮬레이터입니다. 네트워크 속성, 로컬 보안 정책, DHCP, DNS, 웹(IIS), FTP, 로컬 사용자 및 그룹, 서비스를 큰 글자 화면에서 연습하고, 최종 설정값을 조건과 대조해 채점합니다. 빌드 과정이 없는 정적 파일(HTML·CSS·JS)이며 설치와 로그인이 없습니다.

작성: 2026-11-15(4유형 MVP) · 2026-11-16 8유형 전체로 확장, GitHub Pages 공개.

## 만든 원칙

- **가독성 우선**: 작업 화면 글자를 18px(세로 900px 이상 화면은 20px)로 시작하고, 「가−」 「가+」로 16~26px 사이에서 바꿉니다. 모든 창·대화상자·메뉴가 이 크기를 따라 커집니다. 12px 이하 글자는 쓰지 않습니다.
- **Windows 창 색과 느낌**: 파랑 제목 표시줄, 은색 대화상자, 흰 탭 페이지, 회색 단추, 하늘색 선택 표시, 파랑 바탕 화면과 검은 작업 표시줄(2026-11-15 사용자 지시). 창 안 글꼴은 맑은 고딕입니다.
- **칸 이름과 동작**: 실기 시험 연습 프로그램의 한국어 표기를 따랐습니다. Windows Server 2022(영어판) 화면 캡처로 기본값과 동작을 함께 대조했습니다.
- **새로 만든 것**: 과제의 주소·이름·수치·메시지는 모두 연습용으로 새로 정했습니다. Microsoft 아이콘·로고 그림은 쓰지 않았고 아이콘은 단순 도형으로 직접 그렸습니다. 서비스·그룹·정책 설명 문장도 핵심어를 살려 새로 썼습니다.
- 시험 과제에 쓰지 않는 메뉴·탭·기능 아이콘은 비활성으로 두고 「연습 범위 밖」을 표시했습니다.

### 연습 방식

- **과제 연습**: 왼쪽에 문제·조건·작업 순서(닫을 수 있음), 오른쪽에 서버 바탕 화면과 관리 도구 7개(네트워크 연결, 로컬 보안 정책, DHCP, DNS 관리자, IIS 관리자, 컴퓨터 관리, 서비스)가 있습니다. 「채점」은 언제든 누를 수 있고 고친 뒤 다시 채점합니다.
- **시험장 방식**(첫 화면 확인란, 기본 켜짐): 시험처럼 과제를 열면 해당 설정 창이 바로 열립니다. 끄면 바탕에서 알맞은 도구를 직접 고릅니다.
- **실전 세트**: 8유형에서 1문항씩 무작위로 골라 제한 시간 40분 안에 풉니다. 문항 번호 단추와 「이전」 「다음」으로 오가고, 「세트 채점」에서 8문항을 한꺼번에 채점합니다(점검 항목이 모두 맞아야 정답). 시간이 다 되면 자동으로 채점합니다. 진행 중인 세트는 저장되어 이어서 할 수 있습니다.

## 화면에서 재현한 동작

## 채점

항목마다 조건 값과 현재 설정값을 나란히 보여 줍니다. 최종 설정값만 보고 조작 순서는 보지 않습니다.

- 사이트·사용자·그룹 이름, 실제 경로, 암호, 메시지 문장은 대소문자·띄어쓰기·마침표까지 그대로 비교합니다(시험 안내: 이름·암호·경로 대소문자 구분).
- IP 주소는 같은 주소면 통과입니다. DNS 이름은 대소문자와 끝의 점(.)을 구분하지 않습니다.
- SOA 시간 값은 초로 바꿔 비교합니다(7200초를 2시간·120분·7200초 어느 단위로 넣어도 통과).

채점은 이 연습기의 기준이며 실제 시험의 채점 기준은 공개되지 않았습니다. 시험 전 마지막 연습은 협회 자료실의 공식 연습 프로그램으로 합니다.

## 실행 방법

`index.html`을 더블클릭하면 열립니다. 외부 요청은 글꼴(Pretendard, jsDelivr) 하나뿐입니다. GitHub Pages와 같은 조건으로 보려면 이 폴더에서 로컬 서버를 띄웁니다.

```powershell
python -m http.server 8775 --bind 127.0.0.1
```

`http://127.0.0.1:8775/`를 엽니다(ICT폴리텍 저장소 `.claude/launch.json`의 `na2-winsrv`). 주소 뒤에 `?task=ftp-3`처럼 과제 id를 붙이면 그 과제로 바로 들어갑니다. 권장 화면은 PC 브라우저, 가로 1000px 이상(1366×768에서 확인)입니다.

진행 상태·채점 기록·실전 세트는 브라우저 저장소(`localStorage`, 키 `na2-winsrv-v1`)에만 남고 서버로 보내지 않습니다. 앞 버전에서 저장한 진행 상태는 새 항목을 채워 이어서 쓸 수 있습니다. 첫 화면 맨 아래 「연습 기록 모두 지우기」로 지웁니다.

2026-11-16 실행 결과(로컬 서버, 내장 브라우저 1366×768): 39개 과제 모두 통과. 별도로 FTP 기능 페이지를 저장하지 않고 창을 닫으면 반영되지 않는 것, 실전 세트(8문항·40분·문항 이동·한꺼번에 채점)를 확인했습니다.

## 단순화한 부분

- 창은 작업 영역 안에 꽉 차게 열립니다(크기 조절·겹쳐 놓기 없음). 대화상자는 제목 표시줄을 끌어 옮길 수 있습니다.
- 네트워크 속성의 「대체 구성」 「고급」, DHCP 서버 옵션·예약·IPv6, DNS 역방향 영역·기타 레코드, IIS 응용 프로그램 풀·가상 디렉터리·HTTP 응답 헤더 등, 사용자 속성의 프로필·환경 탭, 서비스 속성의 로그온·복구·종속성 탭은 다루지 않습니다.
- IIS의 「사이트 바인딩」에서 https 인증서, FTP의 SSL 인증서는 고를 수 없습니다(SSL은 「없음」만 진행 가능).
- 계정 잠금 기간·원래대로 설정 시간은 임계값이 0일 때 바꿀 수 없게 했습니다.
- 명령 프롬프트(ipconfig, nslookup)는 없습니다.
